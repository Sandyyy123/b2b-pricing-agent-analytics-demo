# Methodological Scope & Synthetic Fixture Note (`README_SCOPE_NOTE.md`)

- **Fixed 12-Month Synthetic Fixture (Non-Causal):** `pricing_analytics.py` generates a deterministic 64-account × 12-month synthetic B2B dataset (`seed=20261105`, 768 invoice rows) solely to demonstrate callable Python function signatures, invoice-to-ledger tie-out (`$0.00` variance), commercial guardrail enforcement, and unit-test coverage. It does **not** use client data or make causal inference claims.
- **24-Month CLV Summary Columns:** In `compute_rfm_retention_clv()`, `clv_24m_p50` reports the **segment mean** discounted 24-month CLV across accounts, and `[clv_24m_p10, clv_24m_p90]` report the **cross-sectional between-account 10th–90th percentile variation** within each segment (not parameter uncertainty).
- **Price-Response Slope & Guardrail Grid:** In `estimate_price_response_and_optimize()`, segment price response is estimated via a within-segment **OLS log-log slope** (`± 1.96 SE`), not arc elasticity or a causal panel estimator. In the synthetic grid search, evaluating negative price steps (`delta_p < 0`) with `elast_ci95_low` reverses the upper/lower response ordering relative to positive price increases; production Milestone 3 models evaluate sign-aware lower-bound profit across the full confidence interval.
- **90-Day & 12-Month Scenario Multipliers:** In `build_forecasts_and_realization_bridge()`, the low/base/high scenario ranges (`0.68x / 1.00x / 1.28x` of base net realized lift) are deterministic sensitivity multipliers, not calibrated predictive quantiles.
